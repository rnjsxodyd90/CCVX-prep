# Syllabus folder — CCVX physics (natuurkunde)

This folder holds the official CCVX syllabus used to build every folder of `CCVX-physics/`.

## Version used

- **File:** [leerstof-natuurkunde.pdf](leerstof-natuurkunde.pdf) — *Leerstof voortentamen natuurkunde van de CCVX*.
- **Document date:** 15 August 2025 (printed on page 1).
- **Status:** this is the **new syllabus, in force from 1 September 2025**. The CCVX registration page carries a notice *"Let op: wijziging leerstof van natuurkunde"* ([Natuurkunde - aanpassing leerstof](https://www.ccvx.nl/Inschrijving/Natuurkunde%20-%20aanpassing%20leerstof.html)): from 1 September 2025 the quantum-mechanics content changed, the parallel-circuit formula changed, `E = mc²` was added, and the Doppler effect was added. The same notice says the current list is the one linked on the CCVX home page; the home page links to exactly this PDF. All content in `CCVX-physics/` therefore follows this version.
- The document itself adds: as long as this list is on the CCVX site it is automatically current, and if the CCVX syllabus deviates from the vwo central-exam programme, the CCVX programme always wins.
- [leerstof-natuurkunde.nl.txt](leerstof-natuurkunde.nl.txt) is a plain-text extraction of the same PDF for search and quoting. The formulas in the PDF are images; the folder notes quote them in text form.

## Sittings on the new syllabus

The new syllabus is in force from 1 September 2025, and physics is examined three times a year (November, April, July), so the first sitting on this version was the November 2025 sitting. The next sitting is Tuesday 24 November 2026, 13:30–16:30, Utrecht. See the subject [README.md](../README.md) for exam details.
