# C7 — Classification of Reactions

- **In Dutch VWO:** school exam (SE) only, so it isn't in the CvTE syllabus. CCVX still tests it.
- **Dutch source:** [SLO handreiking SE (vwo)](https://www.slo.nl/handreikingen/havo-vwo/handreiking-se-schei-hv/toetsen-schoolexamen/vakinhoudelijke-0/) → C7. Recognising reaction types is now also in the central exam: [CvTE 2027](../../syllabus/cvte-syllabus-scheikunde-vwo-2027.pdf) R1.3.

## Learning outcomes (CCVX syllabus)

The candidate is able to classify reactions and describe them in terms of their characteristics:

- thermolysis, photolysis, electrolysis, hydrolysis, saponification, addition, substitution, precipitation, dissolution, redox, combustion, acid-base, condensation, polymerization, reversible/equilibrium reactions, ester formation, synthesis, free radical mechanism.
