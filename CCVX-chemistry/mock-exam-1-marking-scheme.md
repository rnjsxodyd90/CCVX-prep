# Mock exam 1 — Marking scheme

Duration 180 minutes; total 80 points. Open questions marked with partial credit.

**General marking rules:**
- A step marked (•) scores even if carried over from a wrong earlier value (consequential-error rule): use the consistent computed value from the candidate's previous work.
- Correct alternative methods score full marks.
- Per question part: if the final unit is missing or wrong, deduct 1 point (once per part).
- Significant figures score only where the question asks for them. Numerical answers within ±1 in the last digit of the model answer are accepted (intermediate rounding).
- Balancing errors in equations: score (•) only if atoms and charge both balance.
