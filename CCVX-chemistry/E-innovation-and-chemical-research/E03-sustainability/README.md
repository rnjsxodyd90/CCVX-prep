# E3 — Sustainability

- **In Dutch VWO:** school exam (SE) only, so it isn't in the CvTE syllabus. CCVX still tests it.
- **Dutch source:** [SLO handreiking SE (vwo)](https://www.slo.nl/handreikingen/havo-vwo/handreiking-se-schei-hv/toetsen-schoolexamen/vakinhoudelijke-0/) → E3. Overlap: [CvTE 2027](../../syllabus/cvte-syllabus-scheikunde-vwo-2027.pdf) T2 and T6.

## Learning outcomes (CCVX syllabus)

The candidate is able to evaluate and comment on conclusions regarding sustainability, using knowledge of chemical processes:

- sustainable cycles, aspects of green chemistry
- atom efficiency/economy
- coefficient of pollution
- E-factor
- yield
- fossil fuels, electrochemistry.
