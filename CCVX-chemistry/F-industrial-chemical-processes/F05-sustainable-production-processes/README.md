# F5 — Sustainable Production Processes

- **In Dutch VWO:** school exam (SE) only, so it isn't in the CvTE syllabus. CCVX still tests it.
- **Dutch source:** [SLO handreiking SE (vwo)](https://www.slo.nl/handreikingen/havo-vwo/handreiking-se-schei-hv/toetsen-schoolexamen/vakinhoudelijke-0/) → F5. Overlap: [CvTE 2027](../../syllabus/cvte-syllabus-scheikunde-vwo-2027.pdf) T2 (atom economy, E-factor).

## Learning outcomes (CCVX syllabus)

The candidate is able at least in the context of sustainability to give an opinion on the design of production processes, using chemical knowledge:

- large scale, design, judgment, sustainable cycles, green chemistry, laws of conservation, chemical industry, E-factor, atom economy, coefficient of pollution Q.
