# A10 — Using Chemical Concepts

- **In Dutch VWO:** skill, tested inside content questions in both the central exam (CE) and the school exam (SE).
- **Dutch source:** No section of its own in [CvTE 2027](../../syllabus/cvte-syllabus-scheikunde-vwo-2027.pdf): the terms are spread over the spheres (e.g. M1.3, R1.3–R1.4, R&A2.1, L1.1).

> Chromosomes, ecosystem and heredity were dropped from the Dutch syllabus; CCVX still lists them.

## Learning outcomes (CCVX syllabus)

The candidate is able to recognize chemical concepts and the physical and biological concepts used in chemistry and relate them to one another.

1. The candidate is able to recognize and use the following chemical concepts:
    - aggregation state/phase, with the state symbols (s), (l), (g) and (aq); alcohols; ammonia; atomic mass unit (u); greenhouse effect; carbon acids (= carboxylic acids); coefficient; distillate; extracting agent; phase transition; filtrate; index; indicator; mobile phase/eluent; molarity/molar (M); caustic soda; ignition temperature; decomposition reaction: electrolysis, photolysis and thermolysis; incomplete combustion; solvent; reagent; residue; titration; trivial name; calibration line; hydrochloric acid.
2. The candidate is able to recognize and use the following biological concepts:
    - respiration, blood, cell, cell membrane, chromosomes, ecosystem, heredity, organism, digestion, transport.
3. The candidate is able to recognize and use the following physics concepts:
    - pressure, energy, force, light, mass, radioactivity, potential/voltage, radiation, current, temperature, heat.
