# C8 — Technological Aspects

- **In Dutch VWO:** school exam (SE) only, so it isn't in the CvTE syllabus. CCVX still tests it.
- **Dutch source:** [SLO handreiking SE (vwo)](https://www.slo.nl/handreikingen/havo-vwo/handreiking-se-schei-hv/toetsen-schoolexamen/vakinhoudelijke-0/) → C8. Overlap: [CvTE 2027](../../syllabus/cvte-syllabus-scheikunde-vwo-2027.pdf) T1 (block diagrams, reactors).

## Learning outcomes (CCVX syllabus)

The candidate is able in technological contexts to recognize and explain aspects of scale, change and reactivity:

- increasing scale
- reactors, reactivity of chemical reactions
- thermal management
- separation techniques, block diagram
- lab-on-a-chip
- nanoprocesses
- chemistry of atmospheric radicals.
