# C2 — Official specification (CvTE), English translation

> Unofficial translation of [spec.nl.md](spec.nl.md); the Dutch text is the authoritative one. Translated for personal study (the CvTE's reuse permission covers only the unchanged Dutch text). Terms follow the CCVX syllabus where it has one, with the usual English term in brackets.

## Subsphere R&A1: Quantities and relations (pp. 23–24)

**Final attainment level (*eindterm*)**

The candidate is able, using knowledge of chemical reactions and conservation laws, to do calculations on a process.

**Specifications**

1. The candidate is able to use the following principles in calculations on and descriptions of chemical processes:
    - mass ratio;
    - mole ratio/stoichiometric ratio;
    - deficiency/excess (limiting reagent/excess);
    - yield as a fraction or percentage of the theoretical output;
    - volume ratio of gases in reactions.
2. The candidate is able to use the following concepts/quantities and relations in calculations:
    - mass;
        - symbol m
        - unit kg or g
    - atomic mass;
        - symbol A
        - unit u
    - molecular mass;
        - symbol M
        - unit u
    - molar mass;
        - symbol M(X)
        - unit g mol⁻¹
    - chemical quantity (amount of substance);
        - symbol n
        - unit mol
    - volume;
        - symbol V
        - unit m³ or L
    - molar volume (at a given T and p);
        - symbol V<sub>m</sub>
        - unit m³ mol⁻¹ or L mol⁻¹
    - density;
        - symbol ρ
        - unit kg m⁻³ or g L⁻¹
    - concentration;
        - symbol c(X) or [X]
        - unit mol m⁻³ or mol L⁻¹
    - molarity;
        - the symbol is not unambiguous
        - "a M" means an a-molar solution, unit mol L⁻¹ or M
    - charge;
        - symbol Q
        - unit C
    - molar charge, Faraday constant;
        - symbol F
        - unit C mol⁻¹
    - reaction rate;
        - symbol s
        - unit mol L⁻¹ s⁻¹
    - relations:
        - ρ = m / V
        - n = m / M
        - V<sub>m</sub> = V / n
        - [X] = n / V or c = n / V
        - s = Δc / Δt
        - F = Q / n
3. The candidate is able to use the following concepts in calculations with mass, volume and amount:
    - percentage (%);
    - ppm;
    - ppb.
4. The candidate is able to use the following concepts and relations in pH calculations:
    - Acidity:
        - symbols pH and pOH
    - pH = –log [H⁺] or pH = –log [H₃O⁺];
    - pOH = –log [OH⁻];
    - pH + pOH = 14.00 (at 298 K);
    - [H⁺] = 10<sup>–pH</sup> or [H₃O⁺] = 10<sup>–pH</sup>;
    - [OH⁻] = 10<sup>–pOH</sup>;

## Subdomain A8. Scientific instruments, specification 3 (p. 12)

The candidate is able to:

3. explain what is meant by the significance of measured values, and give the results of calculations in the correct number of significant figures:
    - when adding and subtracting measured values, the result is given with as many decimal places as the measured value with the fewest decimal places;
    - when dividing and multiplying, the result is given in as many significant figures as the measured value with the fewest significant figures;
    - whole numbers obtained by counting discrete objects are not subject to the rules for significant figures. This also applies to mathematical constants and amounts of money;
    - when taking the logarithm of a measured value, the answer gets as many decimal places as the measured value has significant figures.

## Appendix 2: Exam verbs (p. 35)

The list below contains the exam verbs relevant to chemistry. When a chemistry exam uses one of these words, the meaning given in this list applies. The list is not exhaustive.

**Calculate (*berekenen*), Determine (*bepalen*):** Establish and/or work out what is asked, starting from data in the question and/or other sources of information. The working must show which formulas and/or principles were applied, which values were used and which steps were taken. The result must be given with the correct unit, unless the unit is stated explicitly in the question. The result must be given in the correct number of significant figures if the question asks for it.

## CCVX's own definitions (English original)

From the CCVX page [Verbs used in the exams](https://www.ccvx.nl/Handelingswerkwoorden%20-%20EN.html), which applies to the CCVX exam itself:

- **Calculate or make a calculation:** to give a quantitative solution (number plus unit) as an answer to the problem posed. The answer must make sense and the calculation must be realistic. The candidate must show which formulae and data he used.
- **Determine:** to define something. For example, to deduce a quantity from a measurement, figure or graph. The answer includes a numerical value and the unit. You can also draw a quantitative or qualitative conclusion based on the data or measurements. Calculations and the use of a table book may be necessary to determine something.
