# D4 — Molecular Modelling

- **In Dutch VWO:** school exam (SE) only, so it isn't in the CvTE syllabus. CCVX still tests it.
- **Dutch source:** [SLO handreiking SE (vwo)](https://www.slo.nl/handreikingen/havo-vwo/handreiking-se-schei-hv/toetsen-schoolexamen/vakinhoudelijke-0/) → D4. Overlap: [CvTE 2027](../../syllabus/cvte-syllabus-scheikunde-vwo-2027.pdf) R2 (mechanisms, polymers) and M1.18 (enantiomers).

## Learning outcomes (CCVX syllabus)

The candidate is able to write a reaction mechanism using molecular modelling, among other things, and knowledge of catalysis if appropriate:

- reaction steps/mechanism
- catalyst
- polymerization
- monomer
- polycondensation, enantiomers, optical activity.
