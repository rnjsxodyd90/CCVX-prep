# B14 — Parametric curves (motion equations)

- **Dutch:** *bewegingsvergelijkingen*
- **CCVX syllabus:** programme point 16 and the section *bewegingsvergelijkingen* of the concept list.

## Learning outcomes (CCVX syllabus)

The candidate can:

1. Use a parametric representation (*parametervoorstelling*): it fixes the position of a point P(x(t), y(t)) with the parameter t; when t is time, these are the motion equations (*bewegingsvergelijkingen*) of the point and the graph is the path (*baan*) of the point.
2. Find the vertices (*toppen van de baan*) of a path: a horizontal tangent where x′(t) ≠ 0 and y′(t) = 0, a vertical tangent where x′(t) = 0 and y′(t) ≠ 0.
3. Recognise paths: for first-degree x(t) and y(t) the path is a straight line, (x, y) = (b, d) + t(a, c); the motion equations x(t) = a + r·cos(t), y(t) = b + r·sin(t) give a circle with centre M(a, b), radius r and equation (x − a)² + (y − b)² = r².
4. Combine periods: when x and y are periodic, the period of the motion is the least common multiple of the periods of x and y.
5. Compute the velocity vector (*snelheidsvector*) v⃗ = (x′(t), y′(t)); the x-speed and y-speed vectors; and the path speed (*baansnelheid*) v = |v⃗| = √((x′(t))² + (y′(t))²).
6. Compute the slope of the tangent to the path at point P: y′(t) / x′(t).
7. Compute the acceleration vector (*versnellingsvector*) a⃗ = (x″(t), y″(t)) and the path acceleration (*baanversnelling*) dv/dt with v the path speed.
8. Apply these techniques in suitable scientific and technical situations.
