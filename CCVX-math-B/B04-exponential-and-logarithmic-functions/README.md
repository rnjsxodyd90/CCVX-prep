# B4 — Exponential and logarithmic functions

- **Dutch:** *exponentiële en logaritmische functies*
- **CCVX syllabus:** programme points 4, 5 and 6, and the sections *exponentiële functies* and *logaritmische functies* of the concept list.

## Learning outcomes (CCVX syllabus)

The candidate can:

1. Analyse the exponential function (*exponentiële functie*) f(x) = aˣ with a > 0: the variable is the exponent; for a > 1 the graph is increasingly increasing with a horizontal asymptote as x → −∞, for 0 < a < 1 it is decreasingly decreasing with a horizontal asymptote as x → ∞.
2. Set up and manipulate the growth formula (*groeiformule*) N(t) = b · gᵗ with initial value b and growth factor g, and compute doubling times (*verdubbelingstijd*) for g > 1 and halving times (*halveringstijd*) for 0 < g < 1.
3. Use the number e ≈ 2.718282 and the natural logarithm ln(x) = ᵉlog(x).
4. Handle the logarithmic function (*logaritmische functie*) l(x) = ᵍlog(x) with g > 0, g ≠ 1 as the inverse of f(x) = gˣ: y = ᵍlog(x) ⇔ gʸ = x; eˣ = y ⇔ x = ln(y); ᵍlog(1) = 0 and ᵍlog(g) = 1; log(x) without a base means base 10.
5. Describe the logarithmic graph: domain x > 0, vertical asymptote x = 0, decreasingly increasing for g > 1, decreasingly decreasing for 0 < g < 1.
6. Apply the rules of logarithms (*rekenregels voor logaritmen*), which follow from the power rules:
   - ᵍlog(a) + ᵍlog(b) = ᵍlog(a·b);
   - ᵍlog(a) − ᵍlog(b) = ᵍlog(a/b);
   - ᵍlog(aⁿ) = n · ᵍlog(a) for all n;
   - change of base: ᵍlog(a) = ᵖlog(a) / ᵖlog(g), often used with p = 10 or p = e for calculator work.
7. Solve exponential and logarithmic equations exactly where possible (ᵍlog(gⁿ) = n) and with logarithms otherwise: gˣ = a ⇔ x = ᵍlog(a); and isolate variables from exponential and logarithmic formulas.
