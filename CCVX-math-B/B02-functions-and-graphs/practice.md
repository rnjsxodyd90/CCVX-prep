### mathb-b02-q01 | points 2 | outcome o1 | difficulty easy

#### Question

For each relation, decide whether y can be written as a function rule of x: (a) x = |y|; (b) x = 3y − 9.

#### Answer

(a) no; (b) yes, y = ⅓x + 3

#### Solution

(a) x = |y| gives y = x or y = −x for every x > 0: two values, so **not** a function rule. (b) y = (x + 9)/3 = ⅓x + 3: one y per x, so yes.

### mathb-b02-q02 | points 3 | outcome o3 | difficulty easy

#### Question

Give the domain and range of f(x) = (x − 2)² + 3 and of g(x) = 1/(x + 2).

#### Answer

f: domain **R**, range y ≥ 3; g: domain x ≠ −2, range y ≠ 0

#### Solution

f: squares always exist, domain **R**; (x − 2)² ≥ 0, so f ≥ 3, range y ≥ 3. g: denominator ≠ 0 gives domain x ≠ −2; the fraction is never 0 and takes every other value, so range y ≠ 0.

### mathb-b02-q03 | points 2 | outcome o3 | difficulty easy

#### Question

Write these intervals as inequalities: (a) ⟨−1, 4]; (b) [0, 6⟩; (c) ⟨←, 2].

#### Answer

(a) −1 < x ≤ 4; (b) 0 ≤ x < 6; (c) x < 2

#### Solution

Round bracket = endpoint excluded, square bracket = included; ← and → stand for −∞ and ∞. So ⟨−1, 4] is −1 < x ≤ 4; [0, 6⟩ is 0 ≤ x < 6; ⟨←, 2] is x < 2.

### mathb-b02-q04 | points 3 | outcome o4 | difficulty medium

#### Question

f(x) = ln(x) and g(x) = 1/(x − 2). Write a rule for h(x) = f(g(x)), simplify it, and give the domain of h.

#### Answer

h(x) = −ln(x − 2), domain x > 2

#### Solution

h(x) = ln(1/(x − 2)) = −ln(x − 2) (logarithm rule for 1/a). The argument of ln must be > 0, so x > 2.

### mathb-b02-q05 | points 3 | outcome o5 | difficulty medium

#### Question

Find the inverse of f(x) = 2^(x+1).

#### Answer

f⁻¹(x) = ²log(x) − 1 (x > 0)

#### Solution

y = 2^(x+1) ⇔ x + 1 = ²log(y) ⇔ x = ²log(y) − 1. So f⁻¹(y) = ²log(y) − 1 with domain y > 0; interchanging letters, f⁻¹(x) = ²log(x) − 1 for x > 0.

### mathb-b02-q06 | points 3 | outcome o6 | difficulty medium

#### Question

Starting from y = x², give the rule of the parabola with vertex (3, −4) obtained by translating, and find where the point (−1, 1) goes.

#### Answer

y = (x − 3)² − 4; the point goes to (2, −3)

#### Solution

Vertex (0,0) → (3, −4): shift 3 right and 4 down: y = (x − 3)² − 4. Every point (a, b) → (a + 3, b − 4), so (−1, 1) → (2, −3). Check: (2 − 3)² − 4 = 1 − 4 = −3 ✓.

### mathb-b02-q07 | points 3 | outcome o6 | difficulty medium

#### Question

Show that f(x) = x⁴ − 3x² has line symmetry in the y-axis, and g(x) = x³ + x point symmetry in the origin.

#### Answer

f(−x) = f(x) and g(−x) = −g(x), as required

#### Solution

f(−x) = (−x)⁴ − 3(−x)² = x⁴ − 3x² = f(x): line symmetry in the y-axis. g(−x) = −x³ − x = −(x³ + x) = −g(x): point symmetry in (0,0).

### mathb-b02-q08 | points 4 | outcome o8 | difficulty medium

#### Question

The graphs of f(x) = x² and g(x) = x + 2 are given.

a. Compute the vertical distance between the graphs at x = 0.

b. Compute exactly where the graphs intersect.

#### Answer

a. 2; b. (−1, 1) and (2, 4)

#### Solution

a. |f(0) − g(0)| = |0 − 2| = 2. b. x² = x + 2 ⇔ x² − x − 2 = (x + 1)(x − 2) = 0 ⇔ x = −1 or x = 2; the intersection points are (−1, 1) and (2, 4).

### mathb-b02-q09 | points 4 | outcome o1 | difficulty hard

#### Question

The relation y² = x + 1 describes a sideways parabola.

a. Explain why y is not a function of x.

b. Give two function rules that together describe the whole relation, with their domains and ranges.

c. At which x does the parabola start, and how does the graph behave at that point?

#### Answer

a. two y-values per x; b. y = ±√(x + 1), x ≥ −1; c. vertex (−1, 0) with a vertical tangent

#### Solution

a. For each x > −1 the relation gives two y-values, ±√(x + 1), so no single function rule exists. b. y₁ = √(x + 1) with domain x ≥ −1, range y ≥ 0 (upper half); y₂ = −√(x + 1), same domain, range y ≤ 0 (lower half). c. The parabola starts at (−1, 0); there the two halves meet and the tangent is vertical — the graph cannot continue left of x = −1.
