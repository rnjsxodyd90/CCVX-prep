# B2 — Functions and graphs

- **Dutch:** *functies en grafieken*
- **CCVX syllabus:** programme points 3, 4, 5 and 6.

## Learning outcomes (CCVX syllabus)

The candidate can:

1. Interpret and manipulate formulas (*formules interpreteren en bewerken*), decide whether a relation between two variables can be rewritten as a function rule (*functievoorschrift*), and draw the graph of a relation between two variables in a coordinate system.
2. Draw and recognise the graphs of the standard functions (*standaardfuncties*) — power functions with rational exponents, exponential, logarithmic and trigonometric functions and the absolute-value function — and name and use their characteristic properties.
3. State the domain (*domein*: all allowed x-values) and range (*bereik*: all possible y-values) of a function; read interval notation.
4. Combine functions (*functies combineren*): add them, multiply by a constant, multiply and divide functions, and form composite functions (*samengestelde functies*) h(x) = f(g(x)).
5. Handle the inverse of a function (*inverse functie*) with understanding: y = f(x) ⇔ x = f⁻¹(y); set up inverses, e.g. x³ ↔ cube root and gˣ ↔ ᵍlog, and use them.
6. Apply the graph transformations (*transformaties*):
   - horizontal translation by c: g(x) = f(x − c);
   - vertical translation by c: g(x) = f(x) + c;
   - scaling relative to the y-axis: g(x) = f(c·x);
   - scaling relative to the x-axis: g(x) = c·f(x);
   - reflection in the y-axis: g(x) = f(−x); in the x-axis: g(x) = −f(x);
   and recognise line symmetry f(−x) = f(x) and point symmetry f(−x) = −f(x).
7. Draw a graph properly (axis values, computed points, asymptotes, domain, range and characteristics readable) and sketch a graph (shape with minima, maxima and asymptotes).
8. Use the vertical distance between two graphs: at x = p it is |f(p) − g(p)|.
