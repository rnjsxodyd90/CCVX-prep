# B6 — Trigonometric functions

- **Dutch:** *goniometrische functies*
- **CCVX syllabus:** programme point 12 and the section *goniometrische functies* of the concept list.

## Learning outcomes (CCVX syllabus)

For periodic phenomena (*periodieke verschijnselen*), the candidate can set up and manipulate formulas, draw the corresponding graphs and solve equations, using the periodicity with insight and the formula sheet where needed. In detail:

1. Work with the standard functions f(x) = sin(x) and g(x) = cos(x), in radians: period 2π, sinusoid (*sinusoïde*) shape, range [−1, 1].
2. State the minima and maxima: sin(x) = −1 at x = −½π + k·2π and cos(x) = −1 at x = π + k·2π; sin(x) = 1 at x = ½π + k·2π and cos(x) = 1 at x = 0 + k·2π; and the zeros: sin(x) = 0 at x = k·π, cos(x) = 0 at x = ½π + k·π (k an integer).
3. Use the symmetry properties (*symmetrie-eigenschappen*): sin(x) = sin(π − x); cos(x) = cos(−x); −sin(x) = sin(−x) = sin(π + x); −cos(x) = cos(π − x) = cos(π + x); and the horizontal translations sin(x) = cos(x − ½π), cos(x) = sin(x + ½π).
4. Read off and determine the parameters of the general sinusoid (*algemene vorm van een sinusoïde*) f(x) = A + B · sin(C · (x − D)): equilibrium level A (*evenwichtsstand*), amplitude |B|, C = 2π/period; for B > 0 the graph rises through the equilibrium at the starting point (D, A).
5. Set up and analyse the harmonic oscillation (*harmonische trilling*) u = a · sin(2π/T · t) with amplitude a, period T and frequency f = 1/T.
6. Solve trigonometric equations exactly (*exact oplossen*): sin(x) = c and cos(x) = c for c = 0, ±½, ±½√2, ±½√3, ±1, using sin(x) = sin(A) and cos(x) = cos(A) with the symmetries, and solve them with inverse functions otherwise: sin(x) = c ⇔ sin(x) = sin(sin⁻¹(c)).
7. Solve equations with composite arguments, e.g. sin(2x − ⅓π) = ½, listing all solutions in a given interval.
