# B9 — Integration

- **Dutch:** *integreren*
- **CCVX syllabus:** programme point 11 and the section *integreren* of the concept list.

## Learning outcomes (CCVX syllabus)

The candidate can:

1. Use the concept of the antiderivative (*primitieve*): F is an antiderivative of f when F′(x) = f(x); then F + C is one too, for any constant C.
2. Write down the standard antiderivatives (*standaardprimitieven*) directly:
   - f(x) = c → F(x) = cx + C;
   - f(x) = xᵃ → F(x) = xᵃ⁺¹/(a+1) + C for a ≠ −1;
   - f(x) = eˣ → F(x) = eˣ + C;
   - f(x) = 1/x → F(x) = ln|x| + C (for x < 0 that is ln(−x) + C);
   - f(x) = sin(x) → F(x) = −cos(x) + C;
   - f(x) = cos(x) → F(x) = sin(x) + C.
3. Apply the rules for integrating combinations: the constant factor rule (c·f integrates to c·F), the sum rule and the simple chain rule (*eenvoudige kettingregel*): f(ax + b) has antiderivative (1/a)·F(ax + b).
4. Compute definite integrals (*bepaalde integraal*) exactly: ∫_a^b f(x) dx = F(b) − F(a), and split an interval: ∫_a^b = ∫_a^c + ∫_c^b for a < c < b.
5. Compute the area (*oppervlakte*) of the region bounded by x = a, the x-axis, x = b and the graph of f ≥ 0 as ∫_a^b f(x) dx; handle regions below the axis with the sign of the integral.
6. Compute the area between two graphs with ∫_a^b (f(x) − g(x)) dx where f is the upper function and g the lower one.
7. Compute the volume (*inhoud*) of a solid of revolution (*omwentelingslichaam*): rotating f about the x-axis gives π ∫_a^b y² dx with y = f(x); rotating about the y-axis gives π ∫_c^d x² dy with x = the inverse function of f.
8. Work with integrals with variable limits (*integraal met variabele grenzen*), e.g. g(p) = ∫_1^p f(x) dx = F(p) − F(1).
