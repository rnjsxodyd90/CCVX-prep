# B7 — Differentiation

- **Dutch:** *differentiëren*
- **CCVX syllabus:** programme points 9 and 10, and the section *differentiëren* of the concept list.

## Learning outcomes (CCVX syllabus)

The candidate can:

1. Compute the derivatives (*afgeleiden*) of the standard functions, in any common notation (f′, dy/dx):
   - f(x) = c → f′(x) = 0;
   - f(x) = xᵃ → f′(x) = a·xᵃ⁻¹ (also for fractional and negative a);
   - f(x) = aˣ → f′(x) = aˣ · ln(a);
   - f(x) = eˣ → f′(x) = eˣ;
   - f(x) = ln(x) → f′(x) = 1/x;
   - f(x) = ᵍlog(x) → f′(x) = 1/(x · ln g);
   - f(x) = sin(x) → f′(x) = cos(x);
   - f(x) = cos(x) → f′(x) = −sin(x).
2. Apply the rules for differentiating combinations of functions (*regels voor het differentiëren*):
   - constant factor rule (*constante factorregel*): (c·f)′ = c·f′;
   - sum rule (*somregel*): (f + g)′ = f′ + g′;
   - product rule (*productregel*): (f·g)′ = f′·g + f·g′;
   - quotient rule (*quotiëntregel*): (f/g)′ = (f′·g − f·g′)/g² — tan(x) = sin(x)/cos(x) is differentiated with this rule;
   - chain rule (*kettingregel*): k(x) = f(g(x)) gives k′(x) = f′(g(x)) · g′(x).
3. Compute second derivatives (*tweede afgeleide*) f″ by differentiating twice, using the same rules and algebraic techniques (expanding, simplifying fractions, rewriting roots as powers) to prepare functions for differentiation.
4. Interpret the derivative: f′(a) is the slope (*helling*) of the tangent line (*raaklijn*) to the graph at the point (a, f(a)); set up the tangent line equation using the slope.
