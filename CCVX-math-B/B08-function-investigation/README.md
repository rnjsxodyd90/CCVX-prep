# B8 — Function investigation: limits, asymptotes, extrema

- **Dutch:** *functieonderzoek: limieten, asymptoten, extremen*
- **CCVX syllabus:** programme points 8 and 9, and the sections *asymptoten en limieten* and *toepassingen van de afgeleide* of the concept list.

## Learning outcomes (CCVX syllabus)

The candidate can:

1. Compute limits (*limieten berekenen*).
2. Determine asymptotic behaviour (*asymptotisch gedrag*) and demonstrate it with limit calculations:
   - horizontal asymptote (*horizontale asymptoot*): y = c when lim (x→∞) f(x) = c or lim (x→−∞) f(x) = c;
   - vertical asymptote (*verticale asymptoot*): x = a when a one-sided limit lim (x↑a) or lim (x↓a) f(x) is ∞ or −∞; for a rational function q(x) = f(x)/g(x) there is one where g(x) = 0 and f(x) ≠ 0;
   - oblique asymptote (*scheve asymptoot*): y = ax + b when lim (x→±∞) (f(x) − (ax + b)) = 0;
   - perforation (*perforatie*): both one-sided limits at a are equal but f(a) does not exist;
   - jump (*sprong*): the one-sided limits at a differ.
3. Use the derivative to describe monotonicity: the graph is increasing (*stijgend*) where f′(x) > 0 and decreasing (*dalend*) where f′(x) < 0.
4. Compute where f can have a minimum or maximum with f′(x) = 0, then check with a sketch of the graph which points give a minimum or a maximum. Together they are called extrema (*extremen*); the corresponding points of the graph are the vertices (*toppen*).
5. Handle touching graphs (*rakende grafieken*): f(x) = g(x) and f′(x) = g′(x); and perpendicular graphs (*loodrecht snijdende grafieken*): f(x) = g(x) and f′(x)·g′(x) = −1.
6. Find inflection points (*buigpunten*): where the derivative has an extreme; there f″(x) = 0. Compute candidates with f″(x) = 0 and use the context.
7. Describe the four kinds of increase/decrease from the signs of f′ and f″: increasingly increasing (*toenemend stijgend*), decreasingly increasing (*afnemend stijgend*), decreasingly decreasing (*afnemend dalend*) and increasingly decreasing (*toenemend dalend*).
8. Count the intersections of the graph with a horizontal line using a sketch, paying special attention to the vertices.
9. Use the angle between two curves in a point P: it is the angle between the tangent lines in P.
