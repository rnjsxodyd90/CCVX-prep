# B3 — Worked examples

Fully worked examples for the outcomes in [README.md](README.md). All examples are original.

## Example 1 — power arithmetic

Simplify to one power of x: (a) x⁶ · x⁻²; (b) (x³)²/x⁴; (c) √x · x³ · x^(1/2).

**Solution.** (a) x⁶⁻² = x⁴. (b) x⁶/x⁴ = x². (c) x^(1/2) · x³ · x^(1/2) = x^(1/2+3+1/2) = x⁴.

## Example 2 — vertex via axis of symmetry and via completing the square

Find the vertex of the parabola y = 2x² − 8x + 5.

**Solution.** Axis of symmetry: x = −(−8)/(2·2) = 2; y(2) = 8 − 16 + 5 = −3, so the vertex is (2, −3). Check by completing the square: 2(x² − 4x) + 5 = 2((x − 2)² − 4) + 5 = 2(x − 2)² − 8 + 5 = 2(x − 2)² − 3. Vertex (2, −3), dalparabool (a = 2 > 0), minimum value −3.

## Example 3 — intercepts and discriminant

How many intersections with the x-axis does y = 3x² − 2x + 4 have? And y = x² − 6x + 9?

**Solution.** First: D = (−2)² − 4·3·4 = 4 − 48 = −44 < 0: none (the parabola lies entirely above the x-axis, as a = 3 > 0). Second: D = 36 − 36 = 0: exactly one, a touching point, x = 3 (indeed (x − 3)²).

## Example 4 — root function analysis

Give the starting point, domain and range of f(x) = −1 + 2√(x − 4), and compute f(8) and f(13).

**Solution.** Start point (4, −1); domain x ≥ 4; the coefficient 2 > 0, so range y ≥ −1. f(8) = −1 + 2√4 = 3; f(13) = −1 + 2·3 = 5.

## Example 5 — line meets root graph

Compute the intersections of y = x − 2 and y = √(x + 4) − 2.

**Solution.** x − 2 = √(x + 4) − 2 ⇔ x = √(x + 4). Square (both sides must be ≥ 0, so x ≥ 0): x² = x + 4 ⇔ x² − x − 4 = 0 ⇔ x = (1 ± √17)/2. Only x = (1 + √17)/2 ≈ 2.56 satisfies x ≥ 0; the other is negative. Then y = x − 2 = (√17 − 3)/2. One intersection: ((1 + √17)/2, (√17 − 3)/2).

## Example 6 — comparing growth

For which x > 0 does x³ exceed 10x²?

**Solution.** x³ > 10x² ⇔ x²(x − 10) > 0. Since x² > 0 for x ≠ 0, this ⇔ x > 10.
