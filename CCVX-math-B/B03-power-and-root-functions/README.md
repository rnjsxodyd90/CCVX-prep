# B3 — Power and root functions

- **Dutch:** *machtsfuncties en wortelfuncties*
- **CCVX syllabus:** programme points 4 and 5, and the sections *machten* and *machtsfuncties* of the concept list.

## Learning outcomes (CCVX syllabus)

The candidate can:

1. Work with powers (*machten*): know the special exponents a¹ = a, a⁰ = 1 (a ≠ 0), a⁻ⁿ = 1/aⁿ (a ≠ 0) and a^(1/n) = the n-th root of a (a ≥ 0 for even n), and apply the power rules (*rekenregels voor machten*):
   - aᵐ · aⁿ = aᵐ⁺ⁿ;
   - aᵐ/aⁿ = aᵐ⁻ⁿ;
   - (aᵐ)ⁿ = aᵐⁿ;
   - (a·b)ⁿ = aⁿ · bⁿ and (a/b)ⁿ = aⁿ/bⁿ;
   - knowing that (a + b)² ≠ a² + b².
2. Draw and recognise the graphs of the power functions (*machtsfuncties*) f(x) = xⁿ with rational n, and describe their behaviour: symmetry, vertices and limits.
3. Use the constant function f(x) = c and the linear function (*eerstegraads functie*) f(x) = ax + b with its straight-line graph.
4. Analyse quadratic functions (*tweedegraads functies*) f(x) = ax² + bx + c:
   - the graph is a parabola with axis of symmetry (*symmetrieas*) x = −b/(2a);
   - opening upwards (*dalparabool*) for a > 0, downwards (*bergparabool*) for a < 0;
   - the number of x-intercepts follows from the discriminant (*discriminant*) D = b² − 4ac;
   - the vertex is a minimum of a *dalparabool* and a maximum of a *bergparabool*.
5. Use the root functions (*wortelfuncties*): f(x) = √x = x^(1/2), the inverse of x² for x ≥ 0, with domain x ≥ 0 and range y ≥ 0 (a half sideways parabola), and f(x) = ∛x = x^(1/3), the inverse of x³, with domain and range **R**.
6. Combine the power rules with these functions: simplify expressions, solve power and root equations, and compare growth of different power functions.
