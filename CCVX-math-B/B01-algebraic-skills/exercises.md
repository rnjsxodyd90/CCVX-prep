# B1 — Practice questions with solutions

Ten original practice questions, written for this prep. Nothing is copied from CCVX or CvTE exams. Solve each question algebraically and exactly; a full worked solution follows every question.

## Q1 — linear equation

Solve: 3(x − 2) − (2x + 4) = 5x − 8.

**Solution.** Expand: 3x − 6 − 2x − 4 = x − 10. So x − 10 = 5x − 8 ⇔ −4x = 2 ⇔ x = −½. Check: LHS = 3(−2.5) − (3) = −7.5 − 3 = −10.5; RHS = −2.5 − 8 = −10.5. ✓

**Answer:** x = −½

## Q2 — quadratic equation, two ways

Solve: 2x² − 7x + 3 = 0.

**Solution.** Factoring: 2x² − 7x + 3 = (2x − 1)(x − 3) = 0 ⇔ 2x − 1 = 0 or x − 3 = 0 ⇔ x = ½ or x = 3. Check with the quadratic formula: D = 49 − 24 = 25, x = (7 ± 5)/4, so x = 3 or x = ½. Same answers.

**Answer:** x = ½ ∨ x = 3

## Q3 — quadratic inequality

Solve: x² + 2x > 3.

**Solution.** Solve the boundary equation: x² + 2x − 3 = (x + 3)(x − 1) = 0 ⇔ x = −3 or x = 1. The graph of y = x² + 2x − 3 is an upward-opening parabola (*dalparabool*), so it is positive outside the zeros.

**Answer:** x < −3 ∨ x > 1

## Q4 — absolute-value equation

Solve: |3x − 1| = 2x + 5.

**Solution.** Two cases. Case 1: 3x − 1 = 2x + 5 ⇔ x = 6. Case 2: 3x − 1 = −(2x + 5) ⇔ 5x = −4 ⇔ x = −4/5. Both candidates satisfy 2x + 5 ≥ 0. Check: |18 − 1| = 17 = 12 + 5 ✓; |−12/5 − 1| = 17/5 = −8/5 + 25/5 ✓.

**Answer:** x = −4/5 ∨ x = 6

## Q5 — root equation

Solve: √(2x + 1) = x − 1.

**Solution.** The right side must be ≥ 0, so x ≥ 1. Square: 2x + 1 = (x − 1)² = x² − 2x + 1 ⇔ x² − 4x = 0 ⇔ x(x − 4) = 0 ⇔ x = 0 or x = 4. Only x = 4 satisfies x ≥ 1. Check: √9 = 3 = 4 − 1. ✓

**Answer:** x = 4

## Q6 — system of two linear equations

Solve: 3x + 2y = 16 and 2x − y = 6.

**Solution.** From the second equation, y = 2x − 6. Substitute: 3x + 2(2x − 6) = 16 ⇔ 7x − 12 = 16 ⇔ x = 4, then y = 2. Check: 3·4 + 2·2 = 16 ✓; 2·4 − 2 = 6 ✓.

**Answer:** x = 4, y = 2

## Q7 — substitution

Solve: x⁴ − 5x² + 4 = 0.

**Solution.** Set y = x²: y² − 5y + 4 = (y − 1)(y − 4) = 0 ⇔ y = 1 or y = 4. So x² = 1 or x² = 4, giving x = ±1 and x = ±2. Check x = 2: 16 − 20 + 4 = 0 ✓.

**Answer:** x = −2, −1, 1 or 2

## Q8 — logarithmic equation

Solve: ²log(x − 1) + ²log(x + 1) = 3.

**Solution.** Domain: x > 1. Sum rule: ²log((x − 1)(x + 1)) = 3 ⇔ x² − 1 = 2³ = 8 ⇔ x² = 9 ⇔ x = 3 (x = −3 is outside the domain). Check: ²log 2 + ²log 4 = 1 + 2 = 3 ✓.

**Answer:** x = 3

## Q9 — isolating a variable

The volume of a cone is V = ⅓π r² h. Express r in terms of V and h (r > 0).

**Solution.** Multiply by 3: 3V = π r² h ⇔ r² = 3V/(πh) ⇔ r = √(3V/(πh)) — the positive root, because r > 0.

**Answer:** r = √(3V/(πh))

## Q10 — parameter: touching the x-axis

For which value(s) of p does the parabola y = x² + px + 4 touch the x-axis? Give the touching point as well.

**Solution.** Touching the x-axis means exactly one intersection, so D = 0. Here D = p² − 16 = 0 ⇔ p = 4 or p = −4. For p = 4: y = x² + 4x + 4 = (x + 2)², touching at (−2, 0). For p = −4: y = (x − 2)², touching at (2, 0).

**Answer:** p = 4, touching at (−2, 0); p = −4, touching at (2, 0)
