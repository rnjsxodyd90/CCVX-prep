# B1 — Algebraic skills

- **Dutch:** *algebraïsche vaardigheden*
- **CCVX syllabus:** programme points 2, 3 and 7, and the *overzicht van algebraïsche vaardigheden*.

## Learning outcomes (CCVX syllabus)

The candidate can:

1. Solve standard equations algebraically and exactly (*standaardvergelijkingen oplossen*):
   - linear (*eerstegraads*): ax + b = px + q;
   - quadratic (*tweedegraads*): ax² + bx + c = 0, with the quadratic formula and, where possible, by factoring;
   - power equations (*machtsvergelijkingen*): xⁿ = a, with the sign rules for even and odd exponents;
   - root equations (*wortelvergelijkingen*): √x = a ⇔ x = a² with x, a ≥ 0;
   - exponential and logarithmic equations, exactly where the equation allows it and with logarithms otherwise;
   - absolute-value equations: |x| = a ⇔ x = ±a (a ≥ 0).
2. Solve inequalities (*ongelijkheden*), computing the intersection points of the graphs algebraically and reading the answer from a sketch.
3. Solve systems of two linear equations (*stelsels van vergelijkingen*) by elimination and/or substitution.
4. Set up the equation of a straight line from a slope or normal vector and a point.
5. Manipulate equations and function rules (*vergelijkingen bewerken*):
   - split equations: A·B = 0 ⇔ A = 0 ∨ B = 0; A² = B² ⇔ A = ±B; A·B = A·C ⇔ A = 0 ∨ B = C;
   - factor out common factors and expand brackets;
   - compute with fractions: common denominators, multiplying and dividing fractions, cross-multiplication A/B = C/D ⇔ AD = BC ∧ BD ≠ 0;
   - compute with roots: √A = B ⇔ A = B² ∧ A ≥ 0;
   - solve equations by substitution, e.g. y = x² or y = eˣ;
   - isolate a variable (*variabelen vrijmaken*) from a formula;
   - substitute formulas into other formulas with correct use of brackets.
6. Work with parameters in function rules (*rekenen met parameters*): treat the parameter as a constant in differentiation and integration and as an extra unknown in equations; use D = 0 to set up an equation for a parameter; find the curve through the vertices of a family of graphs by eliminating the parameter from y = f_p(x) with f_p′(x) = 0; handle touching curves with f_p(x) = g(x) and f_p′(x) = g′(x).
