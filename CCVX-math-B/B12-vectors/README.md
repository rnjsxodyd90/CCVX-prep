# B12 — Vectors

- **Dutch:** *vectoren en inwendig product*
- **CCVX syllabus:** programme point 15 and the sections *vectoren* and *inwendig product* of the concept list.

## Learning outcomes (CCVX syllabus)

The candidate can derive properties of plane figures and carry out calculations using vectors and dot products. In detail:

1. Use the vector concept: a vector (*vector*) gives a displacement over a distance in a direction, with length |v⃗| and a direction; *AB*→ is the displacement from A to B; the zero vector (*nulvector*) has length 0 and no direction.
2. Add vectors (head-to-tail, *kop-staart-methode*) and multiply them by a constant: c·a⃗ points the same way for c > 0 and the opposite way for c < 0, with |c·a⃗| = |c|·|a⃗|.
3. Compute with components (*kentallen*): *OA*→ = (a₁, a₂) is the position vector (*plaatsvector*) of A; addition and scalar multiplication work componentwise; the length is |(a₁, a₂)| = √(a₁² + a₂²); decompose a vector along the axes.
4. Use the dot product (*inwendig product*, short *inproduct*): a⃗ · b⃗ = |a⃗|·|b⃗|·cos α, and in components (a₁, a₂) · (b₁, b₂) = a₁b₁ + a₂b₂, hence cos α = (a₁b₁ + a₂b₂)/(|a⃗|·|b⃗|).
5. Test perpendicularity: two vectors are perpendicular exactly when their dot product is 0 (neither vector being the zero vector).
6. Set up the vector equation of a line (*vectorvoorstelling van een lijn*, also called parametric equation): (x, y) = (a, b) + λ(p, q) with position vector (*steunvector*) (a, b), direction vector (*richtingsvector*) (p, q) and parameter λ.
7. Use the normal vector (*normaalvector*) of a line: a vector perpendicular to the direction vector; the line with direction vector (p, q) has normal (−q, p), and the line px + qy = c has normal (p, q).
