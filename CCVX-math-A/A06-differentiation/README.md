# A6 — Differentiation

- **Dutch:** *differentiëren*
- **CCVX syllabus:** programme point 6 and the section *differentiëren* of the concept list.

## Learning outcomes (CCVX syllabus)

The candidate can determine the derivatives of the standard functions of wiskunde A, use the differentiation rules, and describe the changing behaviour of a function from the derivative. In detail:

1. Differentiate, in any common notation (f′, dy/dx):
   - f(x) = c → f′(x) = 0 and f(x) = ax → f′(x) = a (so ax + b → a);
   - f(x) = axⁿ → f′(x) = n·a·xⁿ⁻¹, also for fractional or negative n;
   - f(x) = eˣ → f′(x) = eˣ (with e ≈ 2.71828);
   - f(x) = gˣ → f′(x) = gˣ·ln(g), with ln(g) = ᵉlog(g);
   - f(x) = ln(x) → f′(x) = 1/x, and from the constant-factor rule f(x) = ᵍlog(x) → f′(x) = 1/(x·ln g).
2. Apply the rules from the formula sheet: constant factor rule, sum rule, product rule (p = f·g → p′ = f′·g + f·g′), quotient rule (q = f/g → q′ = (f′·g − f·g′)/g²) and chain rule (k = f(g(x)) → k′ = f′(g(x))·g′(x), also written dk/dx = df/dg · dg/dx).
3. Use the chain rule only in the exam's limited form: k(x) = f(g(x)) with both f and g single standard functions (such as √(3x + 2), e^(−0.5x), ln(2x), 1/(x + 4)).
4. Prepare functions algebraically before differentiating: split fractions into terms, write roots as powers, expand simple products where easier than the product rule.
5. Use the derivative as slope: f′(a) is the slope of the tangent line at (a, f(a)); set up tangent line equations.
