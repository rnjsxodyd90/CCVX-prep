# A13 — Random variables

- **Dutch:** *toevalsvariabelen*
- **CCVX syllabus:** programme points 12 and 15, and the section *toevalsvariabelen* of the concept list.

## Learning outcomes (CCVX syllabus)

The candidate can:

1. Use a random variable (*toevalsvariabele*) X: when the outcomes of a random experiment are numbers, the probabilities are written P(X = x) (e.g. the number of eyes of a die).
2. Set up the probability distribution (*kansverdeling*) of a random variable with a limited number of outcomes: a table of all values with their probabilities, checking that the probabilities add to 1.
3. Compute the expectation (*verwachtingswaarde*) E(X) = Σ xᵢ·P(X = xᵢ), and interpret it as the long-run average.
4. Compute the standard deviation (*standaardafwijking*) σ(X) = √(Σ (xᵢ − E(X))²·P(X = xᵢ)) — the statistics function of a simple calculator may be used.
5. Use the additivity of expectation (formula sheet): for all random variables X and Y, E(X + Y) = E(X) + E(Y).
6. Use the rules for independent random variables (formula sheet): σ(X + Y) = √(σ²(X) + σ²(Y)) — variances add, not standard deviations.
7. Apply the √n-law (*√n-wet*) for the sum S and the mean X̄ of n independent repetitions of the same experiment: E(S) = n·E(X), σ(S) = √n·σ(X); E(X̄) = E(X), σ(X̄) = σ(X)/√n.
8. In simple cases, use the distribution of S or X̄ (shape by the 68%/95% rules when approximately normal) to interpret outcomes.
