# A14 — The binomial distribution

- **Dutch:** *de binomiale kansverdeling*
- **CCVX syllabus:** programme point 13 and the section *de binomiale kansverdeling* of the concept list.

## Learning outcomes (CCVX syllabus)

The candidate can:

1. State whether a situation is a binomial experiment (*binomiaal kansexperiment*): a fixed number n of independent repetitions (*Bernoulli-experimenten*) of the same success/failure trial, each with the same success probability p; n and p are the parameters (*parameters*) of the distribution.
2. Compute single probabilities (*enkelvoudige kansen*) with the formula from the formula sheet: P(X = k) = C(n,k)·pᵏ·(1−p)ⁿ⁻ᵏ for k = 0, 1, …, n — recognising the "count the orders" role of the combination number C(n,k).
3. Compute cumulative probabilities (*cumulatieve kansen*) P(X ≤ k), P(X ≥ k), P(k ≤ X ≤ l) **only** as sums of at most 3 single probabilities (the exam limits the arithmetic; complement use is allowed and wise).
4. Compute and interpret the expectation E(X) = n·p and the standard deviation σ(X) = √(n·p·(1 − p)) of a binomial random variable.
5. Check the binomial conditions in a described situation (fixed n, independence, constant p, two outcomes) and state when the distribution is *not* binomial (e.g. drawing without replacement changes p).
6. Answer context questions with the distribution: quality control, genetics, games, surveys; translate "more than", "at most", "between" into the right sum of probabilities.
