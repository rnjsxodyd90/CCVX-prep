# A5 — Logarithms

- **Dutch:** *logaritmen*
- **CCVX syllabus:** programme points 4 and 5, and the section *logaritmen* of the concept list.

## Learning outcomes (CCVX syllabus)

The candidate can:

1. Use the definition: y = ᵍlog(x) means gʸ = x (with g > 0, g ≠ 1, x > 0), and translate between the two forms in both directions; use the special values ᵍlog(1) = 0, ᵍlog(g) = 1, ᵍlog(gⁿ) = n; log(x) without a base means ¹⁰log(x).
2. Describe the logarithmic graph: increasing for g > 1, decreasing for 0 < g < 1; domain x > 0; the y-axis as vertical asymptote (the graphs approach the y-axis as x approaches 0).
3. Apply the rules of logarithms (formula sheet): ᵍlog(a) + ᵍlog(b) = ᵍlog(ab); ᵍlog(a) − ᵍlog(b) = ᵍlog(a/b); ᵍlog(aᵖ) = p·ᵍlog(a); and the base change ᵍlog(a) = ᵖlog(a)/ᵖlog(g), often with p = 10 for the calculator.
4. Solve logarithmic equations exactly where possible and with the base change otherwise: ᵍlog(x) = a ⇔ x = gᵃ; and equations that reduce to that form (watch the domain).
5. Manipulate formulas with logarithms: change the base, and isolate a variable from exponential or logarithmic formulas using Y = ᵍlog(X) ⇔ gʸ = X.
6. Convert between log-linear and other formula types: ᵍlog(N) = at + b ⇔ N = B·Gᵗ with B = gᵇ and G = gᵃ (exponential growth); ᵍlog(N) = a + b·ᵍlog(t) ⇔ N = A·tᵇ with A = gᵃ (a power relation).
