# A12 — Probability

- **Dutch:** *kansrekening*
- **CCVX syllabus:** programme point 11 and the section *kansrekening* of the concept list.

## Learning outcomes (CCVX syllabus)

The candidate can use the concept of probability to determine the probability of an outcome or event in a random process, using probability (tree) diagrams, combinatorics and probability rules. In detail:

1. Use events (*gebeurtenissen*): a named selection of the possible outcomes of a random experiment (*toevalsexperiment*), typically with a capital letter.
2. Apply Laplace's probability definition (*kansdefinitie van Laplace*) for experiments with equally likely outcomes: P(G) = (number of favourable outcomes)/(total number of outcomes) — counting done with the techniques of [A11](../A11-systematic-counting/).
3. Estimate empirical probabilities with relative frequencies from repeated observation.
4. Compute with probability trees (*kansboomdiagram*): the probabilities along the branches multiply, the paths add.
5. Compute conditional probabilities (*voorwaardelijke kansen*), typically from a contingency table: P(A given B) = P(A and B)/P(B), read directly as the fraction inside row/column B.
6. Use independence (*onafhankelijke gebeurtenissen*): P(A given B) = P(A); and the product rule for independent experiments: P(G₁ and G₂) = P(G₁)·P(G₂).
7. Apply the sum rule for mutually exclusive events: P(G₁ or G₂) = P(G₁) + P(G₂), and the complement rule: P(not G) = 1 − P(G) — the workhorse for "at least one" problems.
8. Combine these rules in compound random experiments (*samengestelde kansexperimenten*): choose the right scheme (tree, table or combinatorics) and keep fractions exact.
