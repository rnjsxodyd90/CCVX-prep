# A9 — Sine functions

- **Dutch:** *sinusfuncties*
- **CCVX syllabus:** programme point 4 and the section *sinusfuncties* of the concept list.

## Learning outcomes (CCVX syllabus)

The candidate can recognise and use the characteristics of sine functions in graph, table and formula. In detail:

1. Describe the graph of f(x) = A + B·sin(C·(x − D)) as a sinusoid (*sinusoïde*) and give:
   - the equilibrium level (*evenwichtsstand*) A;
   - the amplitude |B|;
   - the period 2π/C, so C = 2π/period;
   - for B > 0: the graph rises through the equilibrium at the starting point (*beginpunt*) (D, A).
2. Read the equilibrium level, amplitude, period and starting point from a given graph, and produce the formula.
3. Determine the equilibrium, amplitude, period and starting point from a given formula.
4. Use the period and the symmetry about the maximum and the minimum of the sinusoid: halfway between two successive maxima there is a minimum; the graph is point-symmetric about each equilibrium crossing and mirror-symmetric about vertical lines through the extremes.
5. Simple formula solving: find all x in a given interval with f(x) = a given level, in cases solvable without the inverse sine (read-off cases and standard symmetry arguments only — this is wiskunde A). Typical task: give the times within one period at which a quantity is above/below a level, using symmetry.
6. Apply sinusoids to contexts: day length through the year, tides, seasonal temperatures; set up the formula from period, extremes and a known moment.
