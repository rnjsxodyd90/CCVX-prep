# A1 — Numbers and algebra

- **Dutch:** *diverse berekeningen; machten en wortels; algebraïsche vaardigheden*
- **CCVX syllabus:** programme point 3 and the sections *diverse berekeningen* and *machten en wortels* of the concept list, with the algebraic skills list.

## Learning outcomes (CCVX syllabus)

The candidate can:

1. Compute with percentages and percentage change: (new − old)/old × 100%, in both directions; use scientific notation (wetenschappelijke notatie), e.g. 0.0000123 = 1.23 × 10⁻⁵.
2. Compute with fractions: adding and subtracting (with common denominators), multiplying, simplifying, dividing (a / (b/c) = a·c/b); use ratios with a ratio table — the cross products are equal.
3. Compute with variables (*rekenen met variabelen*): expand brackets, and isolate a variable (*variabelen vrijmaken*), e.g. from y = 1/(x + 1) to x = 1/y − 1.
4. Compute with units consistently, converting between them (km/h, m/s, per-minute rates).
5. Work with powers and roots (*machten en wortels*): aⁿ with rational n; the n-th root of a; the special exponents a¹ = a, a⁰ = 1 (a ≠ 0), a⁻ⁿ = 1/aⁿ and a^(1/n) = ⁿ√a (a ≥ 0 for even n); and the power rules aᵐ·aⁿ = aᵐ⁺ⁿ, aᵐ/aⁿ = aᵐ⁻ⁿ, (aᵐ)ⁿ = aᵐⁿ, (ab)ⁿ = aⁿbⁿ, (a/b)ⁿ = aⁿ/bⁿ, knowing that (a + b)² ≠ a² + b².
6. Solve the standard equations of the syllabus, exactly:
   - linear: ax + b = px + q;
   - quadratic: ax² + bx + c = 0, with the quadratic formula (formula sheet) or factoring;
   - power equations: xⁿ = a with even n (x = ±ⁿ√a, a ≥ 0) or odd n (x = ⁿ√a); xⁿ = a ⇔ x = a^(1/n);
   - root equations: √x = a ⇔ x = a² with x, a ≥ 0;
   - exponential equations gˣ = a ⇔ x = ᵍlog(a) (logarithms in [A05](../A05-logarithms/)).
7. Solve inequalities, computing the intersection points of the graphs algebraically.
8. Solve systems of two linear equations by elimination and/or substitution; split equations (A·B = 0 ⇔ A = 0 ∨ B = 0; A² = B² ⇔ A = ±B; A·B = A·C ⇔ A = 0 ∨ B = C); factor out; cross-multiply (A/B = C/D ⇔ AD = BC ∧ BD ≠ 0); substitute formulas into formulas with correct brackets.
