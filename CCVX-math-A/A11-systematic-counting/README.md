# A11 — Systematic counting

- **Dutch:** *systematisch tellen* (the syllabus jokes: "for those who master this material, counting (*tellen*) should be no problem (*probleem*)")
- **CCVX syllabus:** programme point 9 and the section *systematisch tellen* of the concept list.

## Learning outcomes (CCVX syllabus)

The candidate can structure and schematise counting problems (*telproblemen*) and use that in calculations and reasoning. In detail:

1. Visualise a counting situation with: a tree diagram (*boomdiagram*), a path diagram (*wegendiagram*), a grid (*rooster*), a contingency table (*kruistabel*) or a Venn diagram (*venndiagram*), and count from the scheme.
2. Apply the multiplication rule (*vermenigvuldigingsregel*) for "I **and** II" (choices in sequence multiply) and the sum rule (*somregel*) for "I **or** II but not both" (disjoint cases add).
3. Count with and without repetition (*met of zonder herhaling*).
4. Use factorials for full orderings: n! orderings of n distinct objects; permutations — count arrangements where the order matters.
5. Use combinations (*combinaties*) where the order does not matter: C(n, k) = n!/(k!·(n−k)!) selections of k from n.
6. Use Pascal's triangle (*driehoek van Pascal*) and read entries as binomial coefficients: sequences with 5 letters A and 3 letters B number C(8,3) = C(8,5) = 56, on the 8th row of the triangle.
7. Combine techniques, e.g. sequences with 3 A's, 4 B's and 5 C's: C(12,3)·C(9,4) (choose positions for the A's, then for the B's); compute and simplify such products exactly (e.g. with prime factors) or with the calculator.
