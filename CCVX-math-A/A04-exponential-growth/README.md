# A4 — Exponential growth

- **Dutch:** *groeiformules*
- **CCVX syllabus:** programme points 4 and 5, and the section *groeiformules* of the concept list.

## Learning outcomes (CCVX syllabus)

The candidate can recognise and use the characteristics of exponential functions in graph, table and formula. In detail:

1. Set up exponential formulas N = b·gᵗ with initial value b (*beginwaarde*) and growth factor g (*groeifactor*) per time unit; the graph of N = gᵗ rises for g > 1, falls for 0 < g < 1 and is constant (degenerate) for g = 1.
2. Convert between growth factor and growth percentage: factor g means (g − 1)·100% growth per unit (negative for g < 1); compute the factor from a percentage in both directions.
3. Convert growth to another time unit (*andere tijdseenheid*) via the growth factor: per k units the factor is gᵏ (also for fractional k, e.g. per week = per-year-factor^(1/52)).
4. Compute the doubling time (*verdubbelingstijd*) for g > 1 and the halving time (*halveringstijd*) for 0 < g < 1 by solving gᵗ = 2 or gᵗ = ½ with logarithms.
5. Back-compute the growth factor from two data points, also over a fractional period.
6. Work with saturation models (*verzadigingsniveau*): N = a(1 − gᵗ) and N = a/(1 + c·gᵗ) with 0 < g < 1 — in both the graph rises towards the boundary value a; compute when N reaches a given value algebraically (for the first form) or by isolating gᵗ (for the second).
7. Recognise exponential behaviour in tables (multiplication by a fixed factor per equal time step) and distinguish it from linear behaviour (adding a fixed amount).
