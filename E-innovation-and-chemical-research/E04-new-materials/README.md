# E4 — New Materials

- **In Dutch VWO:** school exam (SE) only, so it isn't in the CvTE syllabus. CCVX still tests it.
- **Dutch source:** [SLO handreiking SE (vwo)](https://www.slo.nl/handreikingen/havo-vwo/handreiking-se-schei-hv/toetsen-schoolexamen/vakinhoudelijke-0/) → E4. Overlap: [CvTE 2027](../../syllabus/cvte-syllabus-scheikunde-vwo-2027.pdf) M4.2.

## Learning outcomes (CCVX syllabus)

The candidate is able at least in the context of pharmaceuticals, nutrition or materials to explain how new applications are developed in existing and new markets, using knowledge of the chemical industry:

- nanotechnology
- nanocoatings
- ceramic materials
- molecular structure
- antibiotics
- pharmaceutical research.
