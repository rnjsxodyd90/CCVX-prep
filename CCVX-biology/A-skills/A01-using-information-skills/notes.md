# A1 — Using Information Skills: notes

These are English explanations of every learning outcome in [README.md](README.md), and every topic is *drafted*: written from the CCVX syllabus, the Dutch CvTE syllabus and standard VWO biology, not yet checked against an open source text or exam question.

- **In Dutch VWO:** central exam and school exam (CvTE §1.4), always inside a content question.
- **Dutch source:** [CvTE syllabus biologie vwo 2027](https://www.examenblad.nl/2027/vwo/documenten/syllabus-biologie-vwo-2027) (version 2, July 2025), domain A, A1 *Informatievaardigheden gebruiken*. A1–A4 have only an attainment target (*eindterm*), which the CvTE doesn't specify further; a citation like *(CvTE A1)* means that attainment target.

Dutch terms are in brackets. Binas tables are named, not numbered, because the numbers differ between editions.

## What the skill means

- Searching for, judging, selecting and processing information (*informatie zoeken, beoordelen, selecteren en verwerken*). *(CvTE A1)*
- CCVX's "systematically" probably translates *doelgericht*, which means purposefully: aimed at what the task needs.
- A written exam can't test searching a library or the internet, and CCVX leaves out what can't be tested in writing *(CCVX syllabus §1)*. What remains is working with the information printed in the exam: the introduction to a question, its figures, tables and graphs, and tables such as Binas.

## How it shows up in a written exam

- Selecting: an exam context gives more information than one question needs, so find the part that answers it, such as the one row of a table of blood values that changes after training ([B04](../../B-self-regulation/B04-self-regulation-of-organisms/README.md)).
- Processing: combine two sources, for example a graph of blood glucose and one of insulin over the same hours, and say how they relate.
- Judging: decide whether a source fits the question and can be trusted, which is [A09](../A09-evaluation-and-judgment/README.md) item 4; reading data from figures and tables is [A08](../A08-scientific-instruments/README.md) item 1.
- **Trap:** answering from memory when the question says "use figure 2": the answer must quote or use the data given.
