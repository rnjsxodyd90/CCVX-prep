# Basic Knowledge of Physics

This basic knowledge is not tested directly or in isolation from a biological case in the Preliminary Examination.

The following topics are assumed to be known for biology:

- Mass, density, weight
- Solid, liquid and gas phase
- Rates, frequencies
- Types of energy
- Radioactive isotopes and ionizing radiation, half-life
- Electromagnetic spectrum
- Specific heat, heat capacity, heat of combustion
